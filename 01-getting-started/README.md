# Section 1 — Getting Started

Section 1 introduced the foundations required to build and run dependable n8n workflows.

## Topics practiced

- Projects, folders, naming conventions, and tags
- Manual, Schedule, Webhook, Polling, and Chat triggers
- Credential creation and secure reuse
- Header authentication
- Workflow execution and node inspection
- Saving and publishing workflows

## Verified exercise

The first authenticated workflow was successfully registered by the n8n Academy assessment endpoint.

The private assessment identifier and confirmation code are intentionally excluded from this public repository.

## Key lesson

Triggers decide **when** a workflow starts, while credentials securely store the authentication information required to communicate with external services.
